01 Installation

From download to first launch.

  1. 01.

    Install GnuPG

    With Homebrew installed, run this in Terminal. Keep these tools installed for Kleopatra.

    brew install gnupg pinentry-mac
  2. 02.

    Move the app

    Open the DMG and drag Kleopatra 26.08.1 to Applications. Updating from r1? Quit the app before replacing it.

  3. 03.

    Run the self-test

    Open Kleopatra and choose Tools → Perform Self-Test to check the connection to your encryption tools.

Before you open itThis unofficial build was tested on macOS 27.2. It’s locally signed and not Apple-notarized; macOS may ask for approval under Privacy & Security.

03 Field notes

Good to know.

How do I verify my download?

Put the DMG and its checksum file in the same folder. In Terminal, run this from that folder:

shasum -a 256 -c Kleopatra-26.08.1-macos-arm64-r2.dmg.sha256

The result should say OK.

Will it run on my Mac?

This build is for Apple Silicon Macs. The test machine ran macOS 27.2; other versions have not been verified. Intel Macs are not supported. Craft is only needed to build the app.

How do I enable graphical passphrase prompts?

Add or update this line in ~/.gnupg/gpg-agent.conf, preserving other settings:

pinentry-program /opt/homebrew/bin/pinentry-mac

Run gpgconf --kill gpg-agent. The agent restarts when needed.

Where can I find the source or report a problem?

See the build scripts and upstream source references. For packaging problems, open an issue with your macOS version and error message. Leave out private keys and passphrases.
