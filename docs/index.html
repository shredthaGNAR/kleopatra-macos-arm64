Getting started

Three steps to your first launch.

  1. Install the prerequisites

    Install Homebrew for Apple Silicon, then run this in Terminal:

    brew install gnupg pinentry-mac

  2. Move the app

    Download and open the DMG. Drag Kleopatra 26.08.1.app onto the Applications shortcut. If updating from r1, quit Kleopatra before replacing it.

  3. Check your setup

    Launch Kleopatra from Applications. Choose Tools → Perform Self-Test to verify that it can find the encryption tools.

This is a locally signed community build, not an Apple-notarized release. macOS may require approval in System Settings → Privacy & Security. It has only been tested on the builder’s Mac.

A few things to know.

How do I enable graphical passphrase prompts?

Add or update the following setting in ~/.gnupg/gpg-agent.conf, preserving other settings:

pinentry-program /opt/homebrew/bin/pinentry-mac

Then run gpgconf --kill gpg-agent. The agent restarts when needed.

Is this an official KDE release for macOS?

No. This is an unofficial community package of KDE’s Kleopatra application. KDE develops the application; this project shares the Apple Silicon packaging work.

Does it work on Intel Macs?

This package is built for arm64 Apple Silicon Macs. It does not include an Intel build.

Download the SHA-256 checksum. The repository contains upstream source references, local fixes, and build instructions.
